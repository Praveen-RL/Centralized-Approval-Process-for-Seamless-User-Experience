# Tamil Nadu Government House Construction Approval System

A centralized single-window portal for citizens to apply for all construction approvals from the comfort of their homes.

## Features

- User Registration and Authentication
- OTP-based login for Government Officials
- Property Registration with Patta and Chitta Numbers
- Four types of Approvals:
  - Land Approval
  - Water Supply Approval
  - Electricity Connection Approval
  - Sewage and Sanitation Approval
- PDF Document Upload and Preview
- Department-specific Admin Dashboards
- Email Notifications for Status Updates
- Mobile-responsive Design
- Bilingual Support (English and Tamil)

## Technical Stack

- **Backend**: Flask (Python)
- **Database**: PostgreSQL
- **Frontend**: HTML5, CSS3, JavaScript
- **CSS Framework**: Bootstrap 5
- **PDF Handling**: PDF.js
- **Email**: Flask-Mail
- **Authentication**: Flask-Login
- **Forms and CSRF Protection**: Flask-WTF
