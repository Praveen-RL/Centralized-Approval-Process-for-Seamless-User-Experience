I require the development of a Full Stack Centralized Government House Construction Approval System modeled to align with official Tamil Nadu e-Governance standards. The system must be built using Flask (Python) for the backend, PostgreSQL as the database, and frontend technologies including HTML5, CSS3, and JavaScript, without using frontend frameworks like React. This platform must serve as a secure, citizen-centric single-window approval portal supporting two primary roles: Users and Government Department Officers. Both user categories must register via secure email-based registration, and OTP-based authentication must be enforced for every login attempt. Users should go through email OTP verification during registration and for every login, while Government Admin registration must be restricted to official government email domain verification to prevent unauthorized access.

Once authenticated, a user must be able to add multiple properties by submitting the Patta Number, Chitta Number, and the exact Property Address. For each unique property, the system must allow the submission of four distinct approvals: Land Approval, Water Supply Approval, Electricity (EB) Connection Approval, and Sewage and Sanitation Approval. Each approval module must strictly enforce mandatory PDF document uploads, and users must be able to preview every uploaded PDF document before final submission. Supporting text and number fields should accompany each document submission where necessary. Once a request is submitted, users must be able to track its real-time status on a centralized application dashboard with government-specific status terms such as Pending, Under Review, Approved, Rejected, or Resubmission Requested. Additionally, the system must restrict users from submitting multiple approvals for the same property unless a prior request has been officially rejected or flagged for resubmission.

On the administrative side, each of the four approvals must be handled by its respective government department, such as Land approvals by the Revenue Department, Water Supply by the Municipality, Electricity by TANGEDCO, and Sewage by Local Bodies. Government officers must securely log in to their departmental dashboards using OTP-based authentication tied to official email domains. Admin officers must have the ability to preview uploaded PDF documents before taking action and perform one of three actions: Approve, Reject with a reason, or Request Resubmission with a message. Their decision must immediately reflect in the user’s dashboard for that specific property and approval request. Each approval module must enforce document requirements as follows: Land Approval requires Patta & Chitta, FMB Sketch, Plot Plan, and Land Use Classification Certificate (DTCP/CMDA); Water Supply Approval requires Building Plan Approval, Plumbing Layout, Municipal Water Supply NOC, and optionally a Rainwater Harvesting Plan; Electricity Approval requires Owner’s Identity Proof, Completion Certificate, Electrical Test Report, and Load Requirement Application; and Sewage Approval requires a Septic Tank Design or Sewer Connection Plan, Panchayat/Municipality NOC, and Environmental Clearance for large-scale constructions.

The platform must emulate a professional Tamil Nadu Government portal design with an official blue-white color theme, Tamil Nadu state emblem, bilingual Tamil-English text support, formal typography, and full mobile responsiveness. The system should strictly follow security best practices including CSRF protection, password hashing, file upload validation for PDF documents, and secured media storage. Additionally, the system should provide real-time email or SMS alerts for status updates, maintain an audit trail log for government officer decisions, and include document verification timestamps. OTP generation and validation must be done within the system without using external libraries like Flask-Mail, by generating random numeric codes, storing them securely, and verifying them at login screens.

The deliverable must be a well-structured Flask application with separately organized modules or apps for user management, approval workflows, authentication and security, and government admin control panels. The application must include cleanly designed templates, static assets, and detailed developer documentation describing the setup process, API endpoints if any, system architecture, and extension guidelines. The UI/UX must prioritize clarity, formal government styling, and ease of navigation for both citizens and officers. The system should also support optional features such as integration with Tamil Nadu government services for data verification, payment gateway for fee-based requests, and analytical reporting tools for government performance insights.

This complete Centralized Government House Construction Approval System must present a secure, efficient, scalable, and citizen-friendly digital service that simplifies and governs the complex property approval process through a single-window platform for Tamil Nadu.
